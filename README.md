# 🏠 EstateX

An end-to-end **Machine Learning web app** that predicts house prices based on multiple features and explains predictions using feature importance visualization.

Built using **Python, Scikit-Learn, and Streamlit**.

```

```

---

## 📌 Project Overview

This project predicts house prices using a **Linear Regression model** trained on structured housing data.

It also includes a **Streamlit web interface** where users can:

* Input house features
* Get predicted price instantly
* View feature importance visualization
* Understand what factors affect price most

---

## 🧠 Machine Learning Model

* Algorithm: Linear Regression (Scikit-Learn)

* Input Features: (example)

  * Number of rooms
  * Area (sq ft)
  * Location features
  * Age of house
  * Bathrooms, etc.

* Output:

  * Predicted house price

---

## 📊 Feature Importance

The model uses coefficients from Linear Regression to show how each feature affects the price:

* Positive coefficient → increases price
* Negative coefficient → decreases price
* Higher absolute value → stronger impact
